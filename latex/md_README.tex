\chapter{i.\+hyper.\+smac -\/ SMAC Atmospheric Correction for Hyperspectral Data}
\hypertarget{md_README}{}\label{md_README}\index{i.hyper.smac -\/ SMAC Atmospheric Correction for Hyperspectral Data@{i.hyper.smac -\/ SMAC Atmospheric Correction for Hyperspectral Data}}
\label{md_README_autotoc_md245}%
\Hypertarget{md_README_autotoc_md245}%
 A GRASS GIS addon module implementing atmospheric correction for hyperspectral imagery, combining the Simplified Method for Atmospheric Correction (SMAC) with a lib\+Radtran look-\/up table (LUT) approach and ISOFIT-\/inspired enhancements.

{\bfseries{Current Implementation}}\+: The module currently uses the LUT method (lib\+Radtran DISORT) as the default and only implemented method. The simple and libradtran methods are documented for reference but are not yet implemented in this version.\hypertarget{md_README_autotoc_md246}{}\doxysection{\texorpdfstring{Overview}{Overview}}\label{md_README_autotoc_md246}
This module converts top-\/of-\/atmosphere (TOA) radiance to surface reflectance by correcting for atmospheric effects including\+:
\begin{DoxyItemize}
\item Rayleigh (molecular) scattering
\item Aerosol scattering and absorption
\item Gaseous absorption (H2O, O3, O2, CO2, CH4, NO2, CO)
\item Adjacency effects (photon scattering from neighbouring pixels)
\end{DoxyItemize}

Based on the SMAC algorithm by Rahman \& Dedieu (1994) and the implementation by Olivier Hagolle, extended with a lib\+Radtran LUT inversion and techniques from the ISOFIT optimal estimation framework (Thompson et al., 2018).\hypertarget{md_README_autotoc_md247}{}\doxysection{\texorpdfstring{Features}{Features}}\label{md_README_autotoc_md247}

\begin{DoxyItemize}
\item {\bfseries{LUT Method}} (current implementation)\+: Full multiple-\/scattering LUT from lib\+Radtran DISORT with per-\/pixel H2O retrieval and ISOFIT-\/inspired enhancements
\item {\bfseries{Simple Method}} (planned)\+: Fast analytical correction using empirical formulas ~\newline

\item {\bfseries{libradtran Method}} (planned)\+: SMAC coefficients fitted to lib\+Radtran simulations
\item {\bfseries{Hyperspectral Support}}\+: Handles hundreds of spectral bands (400-\/2500nm)
\item {\bfseries{Multiple Sensors}}\+: Pre-\/configured for PRISMA, AVIRIS, AVIRIS-\/\+NG, HYPERION, En\+MAP, Tanager, and more
\item {\bfseries{Open\+CL GPU Acceleration}}\+: GPU and multi-\/core acceleration for faster processing
\item {\bfseries{Automatic Parameter Estimation}}\+:
\begin{DoxyItemize}
\item Aerosol Optical Depth (AOD) using MODIS Dark Target algorithm (Kaufman 1997, Levy 2007) with Dark Pixel and constant fallbacks
\item Water Vapor Content (WVC) using continuum-\/removal band-\/depth at 940nm/1130nm with air mass correction, multi-\/band averaging, and weighted combination
\item Ozone from\+: Chappuis band method (500-\/700nm)
\end{DoxyItemize}
\item {\bfseries{ISOFIT-\/\+Inspired Enhancements}} (LUT method)\+:
\begin{DoxyItemize}
\item Superpixel atmospheric retrieval with spatial interpolation
\item In-\/loop adjacency effect correction (Vermote et al., 1997)
\item Surface reflectance prior (3-\/component Gaussian mixture)
\item Per-\/band reflectance uncertainty propagation
\item MAP inner loop (prior-\/weighted inversion)
\item Model discrepancy matrix (per-\/band RT error floor)
\end{DoxyItemize}
\item {\bfseries{Aerosol Spectral Calibration}}\+:
\begin{DoxyItemize}
\item Native Shettle/\+Fenn aerosol spectral shape (no Angstrom override)
\item Scene-\/retrieved Angstrom exponent from Dark Target
\item NIR transmittance correction from dark vegetation targets
\end{DoxyItemize}
\item {\bfseries{SWIR H2O Accuracy}}\+: Dense 7-\/point H2O LUT grid with log-\/space transmittance interpolation for accurate continuum absorption
\item {\bfseries{Coefficient Generation}}\+: Generate SMAC coefficients using lib\+Radtran or analytical formulas
\item {\bfseries{Four Aerosol Models}}\+: Continental, Maritime, Urban, Desert
\end{DoxyItemize}\hypertarget{md_README_autotoc_md248}{}\doxysection{\texorpdfstring{Project Structure}{Project Structure}}\label{md_README_autotoc_md248}

See \doxysectlink{md_OPENCL__INTEGRATION}{OPENCL\+\_\+\+INTEGRATION.md}{0} for detailed documentation.\hypertarget{md_README_autotoc_md272}{}\doxysection{\texorpdfstring{LUT Atmospheric Correction}{LUT Atmospheric Correction}}\label{md_README_autotoc_md272}
The LUT method (default) uses a precomputed 3D look-\/up table from lib\+Radtran DISORT 16-\/stream simulations. The LUT is indexed by (wavelength, AOD, H2O) and stores four atmospheric parameters\+: path reflectance (R\+\_\+atm), downward transmittance (T\+\_\+down), upward transmittance (T\+\_\+up), and spherical albedo (s).

{\bfseries{Alternative backend}}\+: The companion module \href{../i.hyper.atcorr/}{\texttt{ i.\+hyper.\+atcorr}} implements the same LUT approach using a native C port of 6\+SV2.\+1 (no lib\+Radtran required). It supports all six standard atmosphere profiles, four aerosol models, custom Mie aerosols, and nine BRDF surface models. The Python bindings ({\ttfamily lib/atcorr.\+py} + {\ttfamily lib/libatcorr.\+so}) allow i.\+hyper.\+smac to use the 6\+SV2.\+1 engine without a separate GRASS invocation.\hypertarget{md_README_autotoc_md273}{}\doxysubsection{\texorpdfstring{LUT Generation}{LUT Generation}}\label{md_README_autotoc_md273}
Each LUT is built from two-\/albedo runs (albedo=0 and albedo=0.\+5) across 9 AOD values and 7 H2O values = 126 lib\+Radtran simulations. The dense 7-\/point H2O grid (0.\+3x-\/2.\+5x scene mean) accurately captures the nonlinear H2O continuum absorption in SWIR bands (1500-\/2500nm). Transmittance parameters (T\+\_\+down, T\+\_\+up) are interpolated in log-\/space, since ln(\+T) is nearly linear in H2O column, eliminating the systematic bias from linear interpolation on the convex exp(-\/tau) function. The 6S-\/style decomposition separates direct and diffuse transmittance components.

Generated LUTs are cached as {\ttfamily .npz} files in {\ttfamily COEFS/\+LUT/} and reused when scene geometry matches. Use {\ttfamily -\/c} to force regeneration.\hypertarget{md_README_autotoc_md274}{}\doxysubsection{\texorpdfstring{Per-\/\+Pixel H2\+O Retrieval}{Per-Pixel H2O Retrieval}}\label{md_README_autotoc_md274}
Water vapor is retrieved per-\/pixel from the 940nm absorption band (ISOFIT-\/style). For each H2O value in the LUT grid, the observed radiance at 865nm (shoulder), 945nm (absorption), and 1040nm (shoulder) is inverted. The correct H2O produces a smooth continuum across the absorption feature.\hypertarget{md_README_autotoc_md275}{}\doxysubsection{\texorpdfstring{ISOFIT-\/\+Inspired Processing Pipeline}{ISOFIT-Inspired Processing Pipeline}}\label{md_README_autotoc_md275}

\hypertarget{md_README_autotoc_md286}{}\doxysubsection{\texorpdfstring{SMAC Equation}{SMAC Equation}}\label{md_README_autotoc_md286}
Surface reflectance rho is computed from TOA reflectance rho\texorpdfstring{$\ast$}{*} using\+:


\begin{DoxyCode}{0}
\DoxyCodeLine{rho\ =\ (rho*\ -\/\ rho\_atm)\ /\ (T\_gas\ *\ T\_scat\ *\ (1\ +\ s*rho))}

\end{DoxyCode}


Where\+:
\begin{DoxyItemize}
\item rho\+\_\+atm = atmospheric path reflectance
\item T\+\_\+gas = gaseous transmission (H2O, O3, etc.)
\item T\+\_\+scat = scattering transmission (Rayleigh + aerosol)
\item s = spherical albedo of atmosphere
\end{DoxyItemize}\hypertarget{md_README_autotoc_md287}{}\doxysubsection{\texorpdfstring{LUT Inversion (6\+S-\/style)}{LUT Inversion (6S-style)}}\label{md_README_autotoc_md287}
The LUT method decomposes the atmosphere using two-\/albedo simulations\+:


\begin{DoxyCode}{0}
\DoxyCodeLine{R\_atm\ =\ pi\ *\ L\_toa(albedo=0)\ /\ E0\ \ \ \ \ \#\ path\ reflectance}
\DoxyCodeLine{T\_down\ =\ (E\_dir\ +\ E\_dif)\ /\ E0\_toa\ \ \ \ \ \ \#\ downward\ transmittance}
\DoxyCodeLine{s\ =\ (E\_global(rho1)\ /\ E\_global(0)\ -\/\ 1)\ /\ (rho1\ *\ E\_global(rho1)\ /\ E\_global(0))}
\DoxyCodeLine{T\_up\ =\ pi\ *\ (L(rho1)\ -\/\ L(0))\ *\ (1\ -\/\ s*rho1)\ /\ (E0\ *\ rho1\ *\ T\_down)}

\end{DoxyCode}


The inversion solves\+: 
\begin{DoxyCode}{0}
\DoxyCodeLine{y\ =\ (rho\_toa\ -\/\ R\_atm)\ /\ (T\_down\ *\ T\_up)}
\DoxyCodeLine{rho\_boa\ =\ y\ /\ (1\ +\ s\ *\ y)}

\end{DoxyCode}

Following Vermote et al. (1997), the total transmittance is decomposed into direct (Beer-\/\+Lambert) and diffuse components. The diffuse component picks up signal from the environmental reflectance (spatial average) rather than the pixel reflectance\+:


\begin{DoxyCode}{0}
\DoxyCodeLine{T\_diff\ =\ clip(T\_down*T\_up\ -\/\ T\_dir,\ 0)}
\DoxyCodeLine{r\_env\ =\ spatial\_average(r\_boa,\ PSF\_radius)}
\DoxyCodeLine{correction\ =\ T\_diff\ *\ s\ *\ (r\_boa\ -\/\ r\_env)\ /\ (1\ -\/\ s*r\_env)}
\DoxyCodeLine{r\_adj\ =\ r\_boa\ +\ correction}

\end{DoxyCode}
\hypertarget{md_README_autotoc_md289}{}\doxysubsection{\texorpdfstring{Aerosol Spectral Calibration}{Aerosol Spectral Calibration}}\label{md_README_autotoc_md289}
Three techniques reduce systematic NIR/\+SWIR reflectance bias\+:


\begin{DoxyEnumerate}
\item {\bfseries{Native Shettle/\+Fenn spectral shape}}\+: Aerosol models use their internally consistent spectral properties from lib\+Radtran\textquotesingle{}s {\ttfamily aerosol\+\_\+haze} directive, preserving the physically-\/based spectral variation of AOD.
\item {\bfseries{Scene-\/retrieved Angstrom exponent}}\+: The Dark Target algorithm derives the Angstrom exponent from the blue/red AOD ratio. This is used as the LUT parameter when no explicit override is provided.
\item {\bfseries{NIR transmittance correction}}\+: Dark vegetation targets at 860nm (known surface reflectance \texorpdfstring{$\sim$}{\string~} 3.\+5 x rho\+\_\+\+SWIR) provide an empirical transmittance correction applied to all bands \texorpdfstring{$>$}{>}= 700nm\+: 
\begin{DoxyCode}{0}
\DoxyCodeLine{t\_corr\ =\ rho\_retrieved(860nm)\ /\ rho\_expected(860nm)}
\DoxyCodeLine{T\_eff\ =\ T\_down\ *\ T\_up\ *\ t\_corr}

\end{DoxyCode}

\end{DoxyEnumerate}\hypertarget{md_README_autotoc_md290}{}\doxysubsection{\texorpdfstring{SWIR H2\+O Continuum Accuracy}{SWIR H2O Continuum Accuracy}}\label{md_README_autotoc_md290}
The 7-\/point H2O grid with log-\/space transmittance interpolation addresses the nonlinear absorption in SWIR bands. Since T = exp(-\/tau) and tau is roughly proportional to H2O column, interpolating ln(\+T) rather than T eliminates the convexity bias that linear interpolation introduces. Testing shows this reduces transmittance interpolation error from up to 54\% (old 3-\/point linear) to \texorpdfstring{$<$}{<}0.\+01\% at strong SWIR absorption bands.\hypertarget{md_README_autotoc_md291}{}\doxysubsection{\texorpdfstring{Surface Prior and MAP Estimate}{Surface Prior and MAP Estimate}}\label{md_README_autotoc_md291}
The surface prior is a 3-\/component Gaussian mixture (vegetation, soil, water) with per-\/band diagonal covariance. The MAP estimate blends the observation with the prior\+:


\begin{DoxyCode}{0}
\DoxyCodeLine{r\_map\ =\ (r\_obs/sigma\_obs\string^2\ +\ r\_prior/sigma\_prior\string^2)\ /\ (1/sigma\_obs\string^2\ +\ 1/sigma\_prior\string^2)}

\end{DoxyCode}


The measurement variance sigma\+\_\+obs\texorpdfstring{$^\wedge$}{\string^}2 includes instrument noise, AOD uncertainty, and model discrepancy. In bands with high uncertainty (e.\+g., gas absorption edges), the prior dominates; in clean bands, the observation dominates.\hypertarget{md_README_autotoc_md292}{}\doxysubsection{\texorpdfstring{Uncertainty Propagation}{Uncertainty Propagation}}\label{md_README_autotoc_md292}
Per-\/band reflectance uncertainty combines three sources in quadrature\+:


\begin{DoxyEnumerate}
\item {\bfseries{Instrument noise}}\+: NEDL estimated from dark pixels, propagated as sigma\+\_\+rfl = pi \texorpdfstring{$\ast$}{*} NEDL \texorpdfstring{$\ast$}{*} d\texorpdfstring{$^\wedge$}{\string^}2 / (E0 \texorpdfstring{$\ast$}{*} cos(\+SZA) \texorpdfstring{$\ast$}{*} T\+\_\+down \texorpdfstring{$\ast$}{*} T\+\_\+up)
\item {\bfseries{AOD uncertainty}}\+: +/-\/0.04 AOD perturbation through the LUT inversion
\item {\bfseries{Model discrepancy}}\+: Per-\/band systematic RT error floor, empirically characterized (0.\+5\% baseline, up to 2.\+5\% at gas band edges)
\end{DoxyEnumerate}\hypertarget{md_README_autotoc_md293}{}\doxysubsection{\texorpdfstring{AOD Estimation (\+Dark Target Algorithm)}{AOD Estimation (Dark Target Algorithm)}}\label{md_README_autotoc_md293}
Implements the MODIS Dark Target algorithm (Kaufman 1997, Levy 2007)\+:


\begin{DoxyEnumerate}
\item {\bfseries{Band selection}}\+: Blue (470nm), Red (660nm), NIR (860nm), SWIR (2130nm)
\item {\bfseries{Dark Target pixel selection}}\+: NDVI \texorpdfstring{$>$}{>} 0.\+1, SWIR in 0.\+01-\/0.\+25, 20th-\/50th percentile
\item {\bfseries{Surface reflectance prediction}}\+: rho\+\_\+blue = 0.\+25 x rho\+\_\+\+SWIR, rho\+\_\+red = 0.\+50 x rho\+\_\+\+SWIR
\item {\bfseries{Single-\/scattering AOD inversion}} with Henyey-\/\+Greenstein phase function
\item {\bfseries{Angstrom exponent}} from blue/red AOD ratio, scaled to 550nm. The retrieved exponent is used by the LUT method when no explicit override is provided.
\end{DoxyEnumerate}
