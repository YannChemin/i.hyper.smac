The {\ttfamily i.\+hyper.\+smac} module provides advanced atmospheric correction capabilities for hyperspectral imagery using the Simplified Method for Atmospheric Correction (SMAC) enhanced with lib\+Radtran DISORT calculations. This module implements state-\/of-\/the-\/art atmospheric correction algorithms including automatic aerosol and water vapor estimation, parallel processing, and Open\+CL acceleration.\hypertarget{md_PROGRAMMER__MANUAL_autotoc_md206}{}\doxysubsection{\texorpdfstring{Key Features}{Key Features}}\label{md_PROGRAMMER__MANUAL_autotoc_md206}

\begin{DoxyItemize}
\item {\bfseries{Full lib\+Radtran DISORT Integration}}\+: Multiple scattering atmospheric correction
\item {\bfseries{Automatic AOD Estimation}}\+: Dark Target retrieval algorithm
\item {\bfseries{Water Vapor Retrieval}}\+: Joint optimal estimation and band ratio methods
\item {\bfseries{Smart LUT System}}\+: Scene-\/specific Look-\/\+Up Table optimization (77\% speedup)
\item {\bfseries{Parallel Processing}}\+: Multi-\/core LUT generation with automatic resource detection
\item {\bfseries{Open\+CL Acceleration}}\+: GPU/\+CPU acceleration for atmospheric correction
\item {\bfseries{Uncertainty Quantification}}\+: Per-\/band uncertainty propagation
\item {\bfseries{Adjacency Correction}}\+: Point Spread Function based correction
\item {\bfseries{Spectral Polishing}}\+: ISOFIT-\/inspired spectral smoothing
\end{DoxyItemize}\hypertarget{md_PROGRAMMER__MANUAL_autotoc_md207}{}\doxysection{\texorpdfstring{Installation}{Installation}}\label{md_PROGRAMMER__MANUAL_autotoc_md207}
