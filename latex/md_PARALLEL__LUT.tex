 This document describes the parallel LUT generation feature that dramatically speeds up atmospheric correction by running multiple lib\+Radtran uvspec processes simultaneously.\hypertarget{md_PARALLEL__LUT_autotoc_md89}{}\doxysection{\texorpdfstring{Overview}{Overview}}\label{md_PARALLEL__LUT_autotoc_md89}
The LUT generation in i.\+hyper.\+smac requires running lib\+Radtran\textquotesingle{}s {\ttfamily uvspec} multiple times (typically 156 runs for a full LUT). With parallel processing, these runs are distributed across multiple CPU cores, reducing generation time from hours to minutes.\hypertarget{md_PARALLEL__LUT_autotoc_md90}{}\doxysection{\texorpdfstring{Performance Benefits}{Performance Benefits}}\label{md_PARALLEL__LUT_autotoc_md90}
