{\ttfamily i.\+hyper.\+smac} applies atmospheric correction to hyperspectral imagery using the SMAC (Simplified Method for Atmospheric Correction) algorithm enhanced with lib\+Radtran-\/based Look-\/\+Up Tables (LUTs). The module supports\+:


\begin{DoxyItemize}
\item {\bfseries{Full multiple-\/scattering}} atmospheric correction via lib\+Radtran DISORT
\item {\bfseries{Parallel LUT generation}} using 75\% of available CPU resources
\item {\bfseries{Open\+CL acceleration}} for atmospheric correction pixel processing
\item {\bfseries{Spectral polishing}} to remove outlier bands
\item {\bfseries{Uncertainty quantification}} for atmospheric correction results
\item {\bfseries{Multiple sensor support}} with pre-\/configured parameters
\end{DoxyItemize}\hypertarget{md_i_8hyper_8smac_autotoc_md2}{}\doxysection{\texorpdfstring{KEY FEATURES}{KEY FEATURES}}\label{md_i_8hyper_8smac_autotoc_md2}

\begin{DoxyItemize}
\item {\bfseries{75\% Resource Usage}}\+: Automatically uses 75\% of available CPU resources
\item {\bfseries{Smart Detection}}\+: Auto-\/detects optimal worker count based on CPU cores and RAM
\item {\bfseries{Memory Aware}}\+: Considers system RAM constraints for uvspec processes
\item {\bfseries{Performance}}\+: 6x speedup on 8-\/core systems vs sequential
\item {\bfseries{CPU-\/only}}\+: uvspec runs on CPU with multiple parallel processes
